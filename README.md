# 🏢 컴퍼니 — 회사 경영 멀티플레이어 보드게임

땅을 사고, 공장을 짓고, 시장을 흔들고, 라이벌 회사를 인수하는 실시간 멀티플레이어(2~6인) 경영 보드게임입니다.
방 코드만 공유하면 친구들과 바로 함께 플레이할 수 있고, 게임 내 음성 채팅(WebRTC)을 지원합니다.

## 게임 방법

**턴이 없습니다.** 서버가 계속 돌아가면서 공장은 초당 생산하고 돈은 초당 들어옵니다. 제한 시간(기본 10분) 안에 회사를 키우면 됩니다.

- **생산**: 땅을 사서 건물을 짓습니다. 모든 수치는 초당입니다.
  - 철광 지대 → **광산** (철광석 +0.4/초)
  - 유전 지대 → **시추소** (원유 +0.3/초)
  - 농지 → **농장** (곡물 +0.5/초)
  - 평지 → **공장** — 기계(철광석×2+원유×1, 0.18/초) 또는 식품(곡물×2, 0.22/초)
  - 공장은 **3단계까지 증설**할 수 있습니다. 생산량이 배로 늘고, 물동량이 커져 운송 단가도 내려갑니다.
- **배송 = 자동 판매**: 공장에 **배송 도시**를 지정하면 만들어지는 족족 그 도시로 실려가 팔립니다. 노선을 끄면 재고만 쌓입니다.
  - 운송 수단은 거리와 물동량에 따라 자동으로 가장 싼 것이 선택됩니다.
  - **트럭** — 고정비 없음. 가깝고 물량이 적을 때
  - **기차** — 고정비 있고 거리당 단가가 쌈. 중·장거리
  - **항공** — 고정비가 크지만 거리당 단가가 가장 쌈. 증설한 공장의 대량 장거리 수송
  - 한 도시에 계속 쏟아부으면 그 도시 **수요가 떨어져** 값이 내려가고, 시간이 지나면 회복됩니다. 도시를 나눠 파는 게 유리합니다.
- **자재 시장**: 원자재(철광석·원유·곡물)는 시장에서 사고팔 수 있습니다. 사면 오르고 팔면 내리는 수요·공급 가격이며, 시간이 지나면 기준가로 회귀합니다. 공장이 재료가 없어 멈추면 시장에서 사다 넣을 수 있고, 남는 원자재는 내다 팔 수 있습니다.
- **주식**: 모든 회사는 100주를 발행합니다(창업자 40주 + 시장 유통 60주). 주가는 회사 순자산을 따라가고 매수/매도 시 출렁입니다.
  - 배당: 매출의 15%가 지분에 따라 주주에게 **실시간으로** 흘러갑니다.
  - **경영권 인수**: 남의 회사 주식을 51주 이상 모으면 경영권을 빼앗아 그 회사 매출의 25%를 계속 가져옵니다. 자기 주식을 되사서 방어하세요.
- **승리**: 제한 시간이 끝났을 때 순자산(현금+재고+토지+건물+주식)이 가장 많은 회사가 우승합니다.

## 컴퓨터 플레이어

대기실에서 방장이 **🤖 컴퓨터 추가**를 누르면 AI 회사가 참가합니다(최대 5명). 혼자서도 바로 게임을 시작해 볼 수 있고, 사람이 부족할 때 인원을 채우는 용도로도 씁니다.

컴퓨터는 사람과 똑같은 규칙 안에서 움직입니다(반칙 불가). 매 라운드 이렇게 판단합니다:

1. 만들어 둔 제품을 순수익이 가장 큰 도시로 배송 판매
2. 공장이 쓰고 남는 원자재는 시세가 괜찮을 때 매도
3. 부족한 설비를 하나씩 건설 — 주력 제품(기계/식품)을 정하고 생산기지 → 공장 순으로 확장하며, **공장은 운송비가 싸도록 도시 가까운 자리**를 고릅니다
4. 공장을 놀리지 않도록 모자란 재료를 시장에서 매수 (너무 비싸면 건너뜀)
5. 누가 자기 주식을 36주 이상 모으면 되사서 **경영권 방어**, 여유 자금이 있으면 저평가된 라이벌 지분 매수

## 로컬 실행

```bash
npm install
npm start
```

브라우저에서 http://localhost:7861 접속. 같은 방 코드로 여러 명이 들어오면 함께 플레이합니다.

테스트:

```bash
npm test
```

혼자 테스트할 때는 대기실에서 **🤖 컴퓨터 추가**를 누르면 됩니다.
멀티 접속 자체를 검증하려면 외부 소켓 봇을 붙일 수도 있습니다:

```bash
node test/bot.js http://localhost:7861 방코드 봇이름
```

## 배포 (GitHub + Render)

1. GitHub에 새 저장소를 만들고 푸시합니다.

   ```bash
   git remote add origin https://github.com/<계정>/<저장소>.git
   git push -u origin main
   ```

2. [Render Blueprints](https://dashboard.render.com/blueprints)에서 **New Blueprint Instance** → 이 저장소를 연결하면 `render.yaml`을 읽어 무료 플랜으로 자동 배포됩니다.

3. 배포된 `https://….onrender.com` 주소를 친구들과 공유하세요. 음성 채팅(마이크)은 HTTPS에서만 동작하므로 Render 배포 주소에서는 그대로 사용 가능합니다.

> 무료 플랜은 15분간 접속이 없으면 잠들었다가 첫 접속 때 깨어나는 데 수십 초가 걸릴 수 있습니다.

## 구조

```
server.js          # Express + Socket.IO 서버, 방 관리, 음성 신호 중계
src/room.js        # 방(대기실/설정/라운드 타이머/재접속/봇 진행)
src/game.js        # 게임 규칙 전체 (맵/생산/운송/시장/주식/정산)
src/bot.js         # 컴퓨터 플레이어 AI
public/index.html  # 화면
public/client.js   # 클라이언트 (맵 렌더링, 거래 UI, 채팅)
public/voice.js    # WebRTC 음성 채팅 (P2P 메시)
test/              # 로직 테스트 + 테스트 봇
```
