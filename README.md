# 🏢 컴퍼니 — 회사 경영 멀티플레이어 보드게임

땅을 사고, 공장을 짓고, 시장을 흔들고, 라이벌 회사를 인수하는 실시간 멀티플레이어(2~6인) 경영 보드게임입니다.
방 코드만 공유하면 친구들과 바로 함께 플레이할 수 있고, 게임 내 음성 채팅(WebRTC)을 지원합니다.

## 게임 방법

**턴이 없습니다.** 서버가 계속 돌아가면서 공장은 초당 생산하고 돈은 초당 들어옵니다. 제한 시간(기본 10분) 안에 회사를 키우면 됩니다.

- **생산**: 땅을 사서 건물을 짓습니다. 모든 수치는 초당입니다.
  - 철광 지대 → **광산** (철광석 +0.4/초)
  - 유전 지대 → **시추소** (원유 +0.3/초)
  - 농지 → **농장** (곡물 +0.5/초)
  - 평지 → **공장** — 기계(철광석×2+원유×1, 0.18/초) 또는 식품(곡물×2, 0.22/초)
  - 평지 → **임대 상가** — 재료도 배송도 필요 없이 임대료가 그냥 들어옵니다. 대신 **판 전체에 임대 건물이 늘수록 1채당 임대료가 떨어집니다.** 손이 안 가는 안전한 수입원이지만, 다들 몰리면 재미가 없어집니다.
  - **모든 건물은 6단계까지 증설**할 수 있습니다. 생산량이 단계에 비례해 늘고, 공장은 물동량이 커져 운송 단가도 내려갑니다. 증설비는 단계가 오를수록 비싸지므로(신축비의 1.2배 × 현재 단계), 어느 지점부터는 땅을 더 사는 편이 낫습니다.
  - 건물은 **유지비**가 초당 나갑니다(건축비의 0.25%). 놀리는 공장은 돈만 먹으니 무작정 늘리면 손해입니다.
- **배송 = 자동 판매**: 공장에 **배송 도시**를 지정하면 만들어지는 족족 그 도시로 실려가 팔립니다. 노선을 끄면 재고만 쌓입니다.
  - 운송 수단은 거리와 물동량에 따라 자동으로 가장 싼 것이 선택됩니다.
  - **트럭** — 고정비 없음. 가깝고 물량이 적을 때
  - **기차** — 고정비 있고 거리당 단가가 쌈. 중·장거리
  - **항공** — 고정비가 크지만 거리당 단가가 가장 쌈. 증설한 공장의 대량 장거리 수송
  - 한 도시에 계속 쏟아부으면 그 도시 **수요가 떨어져** 값이 내려가고, 시간이 지나면 회복됩니다. 도시를 나눠 파는 게 유리합니다.
- **하이테크**: 공장을 **반도체**(기계1+원유2) 또는 **자동차**(기계2+반도체1)로 돌릴 수 있습니다. 도시로 배송하지 않고 원자재처럼 **재고로 쌓아 두었다가 시장에서 팝니다.**
  - 재료인 기계를 모으려면 기계 공장의 **배송 노선을 꺼야** 합니다. 도시에 팔 것인가, 하이테크 재료로 쓸 것인가가 선택지입니다.
  - 손이 많이 가는 대신 개당 값이 훨씬 비쌉니다 (기계 60 → 반도체 200 → 자동차 520).
- **자재 시장**: 원자재(철광석·원유·곡물)와 하이테크 제품을 시장에서 사고팔 수 있습니다. 사면 오르고 팔면 내리는 수요·공급 가격입니다.
  - 기준가는 **판 전체의 수요·공급을 따라 움직입니다.** 공장이 늘어 원자재가 귀해지면 값이 오르므로, 쌀 때 사 두는 것이 통합니다.
  - **수량 유지**를 걸어 두면 부족할 때 자동으로 사 옵니다 (공장이 재료 없이 멈추는 것 방지).
- **주식**: 모든 회사는 500주를 발행하지만 **창업자는 50주만 들고 시작합니다.** 자기 주식을 잔뜩 쥐고 있으면 회사를 잘 굴린 것보다 주가 운이 승패를 좌우하기 때문입니다.
  - 나머지는 처음부터 시장에 다 나와 있지 않고 **시간이 지나며 조금씩 상장**됩니다. 그렇지 않으면 아무것도 안 하는 사람이 개장 직후 헐값에 남의 회사를 통째로 사 두고 성장만 받아먹습니다.
  - 주가는 **본업 가치**(현금+재고+땅+건물−빚)에 **수익력**을 더한 값을 따라갑니다. 매출이 늘면 오르고 꺾이면 내려갑니다. 남의 주식을 사 모은다고 내 주가가 오르지는 않습니다.
  - **외인·기관**이 초당 몇 주씩 꾸준히 사고팔아, 사람이 주식을 만지지 않아도 호가가 계속 움직입니다.
  - 순위 자산은 `내 회사 가치 − 남이 가진 내 지분 + 내가 가진 남의 지분`입니다. 남이 내 회사를 사들일수록 내 몫이 줄어듭니다.
  - 주가는 회사 순자산에 **시장 심리**를 곱한 값을 따라갑니다. 심리는 계속 출렁이므로 잘나가는 회사도 30% 넘게 조정받을 수 있습니다. 외부 투자자가 알아서 사고팔기 때문에, 아무도 주식을 만지지 않아도 시세는 움직입니다.
  - **배당은 주가를 따릅니다**: 보유 주식에 대해 `주가 × 0.2%/초`가 실시간으로 들어옵니다. 주가가 오르면 배당도 같이 커집니다.
  - 배당은 그 회사의 현금에서 나갑니다. 남에게 지분을 많이 내준 회사는 그만큼 성장이 느려지고, **자기 주식을 되사면 배당 부담이 사라집니다.**
  - **경영권 인수**: 남의 회사 주식을 51주 이상 모으면 경영권을 빼앗아 그 회사 매출의 25%를 계속 가져옵니다.
- **자산 매각 / 부동산**: 내 땅과 건물은 언제든 팔 수 있습니다.
  - **매각** — 은행에 넘깁니다. 땅값은 전액, 건물값은 70%를 돌려받습니다.
  - **매물로 내놓기** — 원하는 가격을 붙여 다른 회사에 팝니다. 건물째로 넘어갑니다. 남이 탐내는 자원 타일을 선점해뒀다가 비싸게 넘기는 것도 전략입니다.
- **대출**: 총자산의 50%(최소 600)까지 빌릴 수 있고, 이자가 **초당 0.08%** 나갑니다. 현금이 없으면 이자가 원금에 붙어 복리로 불어납니다. 초반에 설비를 빨리 까는 데 쓰세요.
- **공매도**: 남의 회사 주식을 빌려 미리 팔고, 주가가 내려가면 싸게 되사서 차익을 남깁니다. 회사당 40주까지. 주가가 오르면 손실이 나고, 미결제 잔고는 순자산에서 부채로 빠집니다.
- **사건**: 주기적으로 무작위 사건이 터집니다. 원자재 품귀·공급 과잉으로 시세가 뛰거나 무너지고, 도시가 호황·불황을 맞습니다. 짜 놓은 공급망이 계속 최적이지는 않습니다.
- **승리**: 제한 시간이 끝났을 때 순자산(현금+재고+토지+건물+주식−빚−공매도 잔고)이 가장 많은 회사가 우승합니다.
- 게임이 끝나면 방장이 **다시 하기**로 대기실에 돌아가 새 판을 시작할 수 있습니다.

## 컴퓨터 플레이어

대기실에서 방장이 **🤖 컴퓨터 추가**를 누르면 AI 회사가 참가합니다(최대 5명). 혼자서도 바로 게임을 시작해 볼 수 있고, 사람이 부족할 때 인원을 채우는 용도로도 씁니다.

컴퓨터는 사람과 똑같은 규칙 안에서 움직입니다(반칙 불가). 매 라운드 이렇게 판단합니다:

1. 만들어 둔 제품을 순수익이 가장 큰 도시로 배송 판매
2. 공장이 쓰고 남는 원자재는 시세가 괜찮을 때 매도
3. 부족한 설비를 하나씩 건설 — 주력 제품(기계/식품)을 정하고 생산기지 → 공장 순으로 확장하며, **공장은 운송비가 싸도록 도시 가까운 자리**를 고릅니다
4. 공장을 놀리지 않도록 모자란 재료를 시장에서 매수 (너무 비싸면 건너뜀)
5. 누가 자기 주식을 36주 이상 모으면 되사서 **경영권 방어**, 여유 자금이 있으면 저평가된 라이벌 지분 매수

## 로컬 실행

```bash
npm install
npm start
```

브라우저에서 http://localhost:7861 접속. 같은 방 코드로 여러 명이 들어오면 함께 플레이합니다.

테스트:

```bash
npm test
```

혼자 테스트할 때는 대기실에서 **🤖 컴퓨터 추가**를 누르면 됩니다.
멀티 접속 자체를 검증하려면 외부 소켓 봇을 붙일 수도 있습니다:

```bash
node test/bot.js http://localhost:7861 방코드 봇이름
```

## 배포 (GitHub + Render)

1. GitHub에 새 저장소를 만들고 푸시합니다.

   ```bash
   git remote add origin https://github.com/<계정>/<저장소>.git
   git push -u origin main
   ```

2. [Render Blueprints](https://dashboard.render.com/blueprints)에서 **New Blueprint Instance** → 이 저장소를 연결하면 `render.yaml`을 읽어 무료 플랜으로 자동 배포됩니다.

3. 배포된 `https://….onrender.com` 주소를 친구들과 공유하세요. 음성 채팅(마이크)은 HTTPS에서만 동작하므로 Render 배포 주소에서는 그대로 사용 가능합니다.

> 무료 플랜은 15분간 접속이 없으면 잠들었다가 첫 접속 때 깨어나는 데 수십 초가 걸릴 수 있습니다.

## 구조

```
server.js          # Express + Socket.IO 서버, 방 관리, 음성 신호 중계
src/room.js        # 방(대기실/설정/라운드 타이머/재접속/봇 진행)
src/game.js        # 게임 규칙 전체 (맵/생산/운송/시장/주식/정산)
src/bot.js         # 컴퓨터 플레이어 AI
public/index.html  # 화면
public/client.js   # 클라이언트 (맵 렌더링, 거래 UI, 채팅)
public/voice.js    # WebRTC 음성 채팅 (P2P 메시)
test/              # 로직 테스트 + 테스트 봇
```
